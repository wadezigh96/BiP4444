## Implications for BIP4444

1. **Use the proxy addresses** in constructor / config (`0x8004A169…` for Identity). Do not hardcode the implementation address for day-to-day calls — call the proxy.
2. **`ownerOf(agentId)` works** on BSC and is the correct ownership check for membership registration.
3. Registries are **upgradeable proxies** (EIP-1967). Admin/upgrade risk of the upstream ERC-8004 deployment should be noted in security review (dependency risk), but is outside BIP4444 control.
4. Token metadata: name `AgentIdentity`, symbol `AGENT`.
